# 兩塊板子的元件對照表

把 **① 實體板照片、② 理論電路圖、③ 我們的程式** 三份資料逐一比對的結果。
包含跟模擬無關的電阻電容，目的是「一次對到位，之後不用改來改去」。

## 0. 資料來源與比對方法

| # | 來源 | 檔案 | 說明 |
|---|------|------|------|
| ① | 實體板照片 | `docs/螢幕擷取畫面 2026-09-17 132245.png` | 449×890 直式。程式裡一律**逆時針轉 90°** 變成 890×449（主板在左、KDM+ 在右），所有座標都用這個座標系 |
| ② | 理論電路圖 | `docs/LTC_KDM使用說明_V4.2.pdf` 第 4–5 頁（圖4 主板）、第 6–7 頁（圖5 KDM+） | 用 `pypdf` 把內嵌點陣圖抽出來看（`page.images`），解析度 2000–2400px，字看得很清楚 |
| ③ | 我們的程式 | `web/src/ui/headers.js`（排針）、`web/src/ui/board.js`（其餘元件） | 座標單位 = 照片像素，畫的時候乘 2 |

**座標怎麼量的（不是估的）**

1. `rot.png` = 照片逆時針轉 90°。
2. 掃描金色焊點：`R>120 and G>95 and B<110 and R-B>60 and G-B>40`，把一個矩形區域裡符合的像素
   分別投影到 x 軸與 y 軸，取連續區段的中心 → 得到每一支腳的位置與間距。
3. 掃描紅色板材：`R>70 and R-G>28 and R-B>25`，逐欄找第一個/最後一個紅色像素 → 得到板子外框。
4. 改完一定要 `node tools/render-board.mjs` 算成圖，再跟照片**各 50% 透明度疊起來**確認。

量到的 2.54mm 排針間距落在 **8.4–9.7 照片像素**之間（照片有透視，不同位置略有差異）。

## 1. 三個系統性規律（先看這個，可以省很多時間）

### 規律 A — 電路圖的腳位編號跟實體絲印是**相反**的

已確認的五個排針全都一樣：

| 排針 | 電路圖 腳1 → 腳N | 照片絲印 左→右（或上→下） |
|------|------------------|---------------------------|
| 主板 JP1 (I2C) | SCL, SDA, WP0, GND | GND, WP, SDA, SCL |
| 主板 JP10 (V4EX) | SCK, SDI, SDO, ADC_CS, DAC_CS, LD, VCC, GND | GND, VCC, LD, DAC, ADC, SDO, SDI, SCK |
| 主板 JP11 (LM35) | GND, CH1, CH1, Vo | Vo, CH1, CH1, GND |
| KDM+ JP3 (SEG) | seg1(a) … seg8(dp) | dp, g, f, e, d, c, b, a |
| KDM+ JP4 (com) | J20(X0) … J27(X7) | D7, D6, D5, D4, D3, D2, D1, D0 |

→ **訊號完全一樣，只是編號方向相反。** 程式裡一律照「照片絲印的順序」排，這樣點畫面上第幾支腳
就對應到你眼睛看到的第幾支腳。

### 規律 B — 有些元件的編號，實體絲印跟電路圖不一樣

| 元件 | 電路圖 | 實體絲印 | 以哪個為準 |
|------|--------|----------|-----------|
| LM35 類比溫度計 | U6 | **U5** | 絲印（你在板子上找得到的那個） |
| KDM+ 的 ULN2803A | U4 | **U4** ✓ 一致 | — |

（另外要注意：網路上找得到的 KT-89S51 **V3.3** 圖片，KDM+ 的 ULN2803 標成 U3、步進馬達控制排針
標成 JP6、電源排針標成 JP9 —— 那是舊版，**跟你這塊 V4.2 不一樣**，不要拿來對。）

### 規律 C — 「電路圖上有焊接」≠「那支針不能接」

JP2 的 RS / R/W / EN / D0–D7 在板子上就焊到 P3.2 / P3.1 / P3.0 / P0.0–P0.7。
這代表**那支腳在電氣上就是那個埠腳位**，不是「被佔用所以不能碰」。
程式已改成：這些腳直接帶著自己的埠訊號，一樣可以點、可以拉線，點下去跟點 JP3 上的 P0.0 是同一件事。
JP5 BT04 的 RXD / TXD（= P3.0 / P3.1）同理。

> ⚠ **JP7 的絲印跟電路圖不一致，這是這次抓到的真 bug。**
> 電路圖：JP7 腳1–4 = S0 S1 S2 S3 → RP1 10K 上拉 → ULN2803A 的 IN1 / IN3 / IN5 / IN7
> → 輸出 OUT1 / OUT3 / OUT5 / OUT7 = **B2 / B1 / A2 / A1**。
> 板子絲印卻印成一串「**B2A2B1A1**」。
> 程式**以電路圖為準**（B2→S0、B1→S1、A2→S2、A1→S3），因為那才決定實際行為。
> 修正前程式把 B2 的訊號送到 A1 的線圈，馬達轉的方向和步序都是錯的。
> 如果你用實體板量出來是絲印那個順序，跟我說我改。

## 4.6 每一支腳現在的角色（161 支，全部有分類）

畫面上的顏色就是角色，板子下方有圖例：

| 顏色 | 角色 | 支數 | 能做什麼 |
|------|------|------|----------|
| 金 | 可接線 | 101 | 埠腳位（含 JP2／JP5 板上焊死的那些）與 KDM+ 訊號腳。點兩支腳接線 |
| 紅 | VCC / +5V / VDD | 12 | 點它抓住，再點任一支埠腳 → 那支腳被硬拉成 1 |
| 深灰 | GND / VSS | 18 | 同上，拉成 0。課本 2-7-2「用杜邦線碰 GND」就是這個 |
| 紫 | RST / EA | 2 | 只能接電源軌。RST 接 VCC → 晶片被按住重置，程式真的不跑；EA 接 GND → 警告本板沒有外接 ROM |
| 黃 | JP11 跳線帽 | 2 | 點一下開關。裝上 = LM35 → ADC CH1，拔掉 = CH1 浮接讀 0V |
| 青 | 輸出腳 | 3 | DAC CHA／CHB 與 ADC CH1，數值在「類比 / 環境」面板。類比訊號沒有可接的數位對象 |
| 灰藍 | 出廠接好 | 6 | CN3 的馬達六條線 |
| 灰 | 真的無法模擬 | 15 | 見下表 |

**電源軌跳線的電氣行為跟真的一樣**：接 GND 就是硬拉低，程式寫 1 也讀回 0；接 VCC 之後程式若對該腳寫 0，
就是把 VCC 短路到地 —— 模擬器記成電氣衝突並警告，不會假裝沒事。同一支腳如果既接了 KDM+ 訊號又跳了電源軌，
畫面會標紅。

### 剩下這 15 支真的做不到

| 腳 | 為什麼 |
|----|--------|
| JP3 `ALE` `PSEN` | 外部記憶體匯流排訊號，模擬器沒有外部匯流排 |
| JP3 `X1` `X2` | 石英振盪腳，模擬器用固定 12MHz 時脈 |
| JP2 `VO` | 液晶對比電壓，模擬的畫面一律清楚顯示 |
| JP6 `R` `G` `B` | 電路圖圖4 沒有這顆 RGB LED，查不到它接到哪 |
| JP4 `中` | 中文 14432 LCM 的型式選擇，模擬器只做 16×2 英文 |
| KDM+ JP2 `12V` `5V` | 馬達供電電壓，模擬器不模擬扭力 |
| JPX `?` ×4 | 還沒查出這個插座是什麼 |
